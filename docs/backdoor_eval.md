Generated by `benchmarks/backdoor_eval.py`. CIFAR-10 (`uoft-cs/cifar10` @ `0b2714987fa4`), target class 0 (airplane), 12 training epochs per model, identical recipe for clean twins.

## Reading these numbers

- Sample sizes are small (6 implanted backdoored models, 4 clean twins), so the confidence intervals are wide.
- The Aegis fuzzer only knows magnitude-amplifying triggers and its own trigger families (Gaussian scales, boundary values, checkerboard patches). Triggers it cannot produce, such as blends and warps, are expected to be hard for it.
- Neural Cleanse ran with a reduced step budget for runtime; ART's default is 1000 steps.
